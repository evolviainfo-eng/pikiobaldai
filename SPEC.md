# Pikio baldai — build spec (locked)

Static multi-page LT site. Vanilla HTML/CSS/JS, pages generated by `gen.py` (stdlib only) from
`assets/data/site.json`, `assets/data/projects.json`, `assets/data/media.json`.
Dev server `fs-server.js` on **port 3093**. No frameworks, no Lenis, no GSAP.

Client: MB „Pikio baldai“ (Kaunas) — nestandartiniai korpusiniai baldai. Target: premium furniture
studio, not a catalogue. Photography carries the page; restraint everywhere else.

## 0. Hard rules (any violation = rework)
- **No em-dash (—) anywhere** (HTML, alt, meta, JSON output). Avoid en-dash as punctuation too.
- No fabricated facts, numbers, dates. Only text from the JSON files. No dates on projects or reviews.
- Banned: scroll hints ("Slinkite" etc.), count-up numbers, marquees/tickers, custom cursor, magnetic
  buttons, particles/grain, rotating badges, letter-split text, parallax on text, decorative giant
  numerals, numbered cards (01/02/03), decorative mono-caps microlabels, emoji, pill buttons,
  giant faint footer wordmark, `transition: all`, CSS keyword easings (`ease`, `ease-in-out`, `linear`).
- **Photos are never hidden/revealed** (no opacity/clip/wipe reveal on images). Images are visible
  immediately; only text/UI reveal. Allowed image motion: hero settle (scale), hero parallax,
  card hover zoom, lightbox, crossfade swaps, view-transition morph.
- Logo is the real PNG from `media.json` — never recreated with CSS/SVG/fonts.
- Every hover rule inside `@media (hover:hover) and (pointer:fine)`.
- Fail-to-visible: hidden reveal states only under `html.js-anim` set by JS. Reduced motion:
  CSS override **and** JS branch that marks everything revealed.
- `100svh` not `100vh`. No horizontal overflow at 375 px (verify-fit gate).

## 2. Type: Josefin Sans only (self-hosted variable woff2, latin + latin-ext, wght 100–700)
Download from Google Fonts css2 API (`family=Josefin+Sans:wght@100..700`), save to `/fonts/`,
`font-display:swap`, preload the latin file. Metric-compatible fallback: `local("Futura"), Arial` with
`size-adjust` tuned so the swap does not shift layout noticeably.
- `.t-hero` h1: `clamp(44px, min(6.1vw, 10.6svh), 96px)`, wght 200, lh 1.02, ls -0.02em, max 13ch.
- `.t-h2`: `clamp(34px, 4.3vw, 66px)`, wght 200, lh 1.05, ls -0.015em.
- `.t-h3`: `clamp(24px, 2.4vw, 36px)`, wght 250, lh 1.14, ls -0.01em.
- `.t-title` (cards): 19px (1.1875rem), wght 400, lh 1.3.
- `.t-lead`: `clamp(18px, 1.3vw, 21px)`, wght 300, lh 1.6, color ink-2, max 36em.
- body: 17px (1.0625rem), wght 350, lh 1.65, color ink.
- `.t-small`: 15px, wght 400, lh 1.55.
- `.t-label` (functional only: nav, buttons, tabs, form labels, spec `dt`, stage labels):
  12px, wght 500, uppercase, ls 0.22em.
- `.t-figure`: `clamp(72px, 9vw, 132px)`, wght 100, lh .9, ls -0.03em, lining+tabular nums.
- `font-feature-settings:"kern","liga"`; numbers/phones `font-variant-numeric: lining-nums tabular-nums`.
- `text-wrap: balance` on headings, `pretty` on paragraphs. Links: no default underline; draw
  underline with `text-decoration-thickness:1px; text-underline-offset:4px` where needed.
- Josefin sits optically low/high in boxes: buttons and tabs must look vertically centred in a
  screenshot. Use `text-box: trim-both cap alphabetic` with `@supports`, and a padding fallback.
  Verify by pixels.

## 3. Components
- **Container**: `.wrap{max-width:var(--max);margin-inline:auto;padding-inline:var(--gutter)}`;
  12-col grid `.grid{display:grid;grid-template-columns:repeat(12,minmax(0,1fr));column-gap:var(--gap)}`.
- **Buttons**: `.btn` ink bg, paper text, `.t-label`, padding 18px 44px, min-height 54px, gap 14px,
  trailing arrow glyph "→" that moves 4px on hover; hover bg `--umber-2`; `:active` scale(.97)
  160ms utility; `:focus-visible` 2px brass outline offset 3px. `.btn--line`: transparent,
  1px ink/.35 border → ink on hover. `.btn--light` for dark grounds (paper bg, ink text).
- **Drawer-handle link** `.handle-link` (brand move, from the dresser in the logo): text + a short
  brass rule after it (`::after`, 28px × 1px) that extends to 48px on hover (transform scaleX,
  origin left). Used for “Visi projektai”, “Visas projektas”, captions that link.
- **Nav** (fixed): height 88px desktop / 64px mobile. Logo left (dark PNG, height 58px desktop,
  44px mobile; use srcset). Links `.t-label` with brass 1px underline on `[aria-current]` and on
  hover (scaleX). Right: phone (tabular, 15px) + `.btn--line` “Užklausa” (→ `/kontaktai/` on
  subpages, `#uzklausa` on home). Over the home hero: transparent with a soft paper gradient
  (paper/.7 → 0, 140px) behind it. After 40px scroll: `background: rgb(245 242 237 / .9)`,
  `backdrop-filter: blur(14px)` (only blur on site), bottom hairline. `view-transition-name: nav`.
  Mobile (<1024): logo + “Meniu” button (44×44+). Menu = full-screen paper `<dialog>`:
  links in `.t-h3` stacked with hairlines, then phone `.btn`, “Užklausa” `.btn--line`, FB/IG text
  links; “Uždaryti” button; Esc closes; focus trapped by dialog; body scroll locked.
- **Mobile call bar** (<768): fixed bottom, 2 halves: “Skambinti” (tel:) and “Užklausa”; appears
  (translateY) only after the hero has scrolled out, hides while the form section is on screen;
  `padding-bottom: env(safe-area-inset-bottom)`; footer gets bottom padding so nothing is covered.
- **Cards** `.card`: `<a>` with `<figure>` (fixed aspect via class, `overflow:clip`, img
  `object-fit:cover; object-position: var(--fx) var(--fy)`), hover: img scale 1.035 over 900ms
  secondary + handle-link extends. Caption: `.t-title` + `.t-small` meta in ink-2 (project
  `card_meta`), category names as plain small text (not chips). Card image gets
  `style="view-transition-name:p-<slug>"`. If project has video, show a small play glyph
  (SVG, 1.25px stroke) + “Video” in `.t-label` at the caption end (functional).
- **Filter tabs** `.tabs`: `role="tablist"`-like buttons with `aria-pressed`; label + count
  (small tabular superscript). One absolutely positioned brass indicator (2px) that moves with
  `transform` to the active tab (secondary curve). Mobile: single row, `overflow-x:auto`,
  hidden scrollbar, right-edge fade mask; active tab scrolled into view.
- **Picture helper** (gen.py): `picture(ref, sizes, cls, alt, eager=False)` → `<img srcset
  sizes width height loading decoding style="background:<bg>">` from media.json widths. Hero =
  `<picture>` with desktop/mobile sources + `fetchpriority="high"` + `<link rel=preload>`.
- **Video** `.vid`: `<video muted playsinline loop preload="none" poster>` with webm + mp4
  sources; plays when ≥40% in view (IO), pauses when out; a small play/pause toggle button
  (bottom-left, 44px, aria-label). `prefers-reduced-motion`: never autoplay, show play button.
  Guards: skip autoplay if `navigator.webdriver` or `window.self !== window.top` (harness deadlock);
  set `src` only on first intersection. Safari/iOS: mp4 source first on Apple UA.
- **Lightbox**: native `<dialog>`; image fits viewport; prev/next buttons, arrow keys, Esc,
  swipe (pointer events, velocity threshold), counter “3 / 7” (`.t-label`), caption = alt;
  backdrop umber/.94; open anim scale .96→1 + fade (secondary); focus returns to trigger.
- **Accordion** (FAQ): `<details>`-free custom: button + panel with `grid-template-rows 0fr→1fr`
  (secondary). Icon = two 1px brass lines forming “+”; open → vertical line scales to 0 leaving a
  horizontal “handle”. `aria-expanded`, `aria-controls`. First item closed by default.
- **Reveal**: `.rv` (fade + translateY(var(--rise)), primary curve, d-primary) on text blocks only;
  `.rv-line` hairlines draw with `scaleX(0→1)` origin left; word mask reveal `.mask-words` for
  exactly 3 headings (home hero h1, flagship h2, materials h2): each word in
  `<span class=w><span>word</span></span>` with `white-space:pre`, inner span translateY(105%)→0,
  stagger 45ms, `padding-bottom:.12em; margin-bottom:-.12em` on the mask so diacritics/descenders
  (ą ę į ų j) are not clipped. IO threshold .15, rootMargin 0 0 -8% 0; unobserve after reveal;
  safety sweep after 2500ms reveals only elements whose rect intersects the viewport; `load` and
  `visibilitychange` sweeps; if IO missing or reduced-motion → reveal all.
- **Page transitions**: CSS cross-document view transitions:
  `@view-transition{navigation:auto}`; root old: opacity→0 + translateY(-8px) 260ms secondary;
  new: opacity 0→1 + translateY(12px→0) 520ms secondary; `::view-transition-group(p-*)` morph
  520ms secondary (use `view-transition-class: proj` on card/lead images and style
  `::view-transition-group(*.proj)`). Disabled under reduced motion. Unsupported browsers: normal nav.

## 5. Form (shared partial, home S10 + `/kontaktai/`)
Native POST, `enctype="multipart/form-data"`, `action` = brand.form_endpoint.
Fields: Vardas* (autocomplete name), Telefonas* (type tel, autocomplete tel, pattern allows
+370 / spaces), El. paštas (email, optional), “Kokių baldų reikia?” = checkbox chips from
contact.types (styled as square toggles with brass check; name `Baldai[]`), Miestas (select:
cities + “Kita vietovė”), “Trumpai apie projektą” (textarea 5 rows, placeholder
“Patalpa, apytiksliai matmenys, pageidavimai”), “Patalpos nuotraukos ar planas” (file, multiple,
`accept="image/*,.pdf"`, name `attachment`), hidden `_subject` “Nauja užklausa iš svetainės”,
`_template` “table”, `_captcha` “false”, `_next` (JS sets `location.origin + '/aciu/'`),
honeypot `_honey` (visually hidden, `tabindex=-1`, `autocomplete=off`).
File UI: styled drop zone (dashed 1px ink/.3, drag-over state brass), list of chosen files with
name + size + remove button (rebuild `input.files` via DataTransfer). Validation: total ≤ 10 MB,
max 6 files, types image/pdf → inline error. Labels always visible above inputs; inputs 52px min
height, 16px+ font; focus ring brass 2px offset 2px; errors under the field in `--error` with
`role="alert"`, validate on blur and on submit, focus first invalid. Submit `.btn` contact.submit;
while submitting: disabled, `aria-busy`, text “Siunčiama…”. Under the button: contact.after and
contact.privacy in `.t-small` ink-2.
**Never submit the form during QA** (it would email the client and trigger FormSubmit activation).
Test validation/states by intercepting `submit` in the browser console.
